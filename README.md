# 개미굴 (ant-nest)

Claude Code 옆 창에서 일본왕개미 3년차 군락이 계속 살아 움직입니다. 접속해 있는 동안 2초가 게임 1시간이고, 계절이 바뀌고, 새끼가 땅속 온도에 따라 자랍니다.

군락의 먹이와 날씨는 당신의 AI 활용입니다. 코드나 대화 내용은 읽지 않고, 도구 이름과 성공 여부만 봅니다.

- 탐색(파일 읽기, 검색, 웹 조사) → 채집 개미가 나가 단물을 가져온다
- 편집·작성 → 굴착, 새 방
- 테스트·빌드 통과 → 사냥 성공, 단백질 (병정개미가 자란다)
- 서브에이전트에 일을 맡김 → 여왕이 알을 더 낳는다
- 오류 → 입구 근처에 거미줄
- 같은 도구 오류가 3번 → 지네 침입, 경보 페로몬이 퍼지면 개미들이 몰려든다
- 실패했던 도구가 다시 성공 → 버그를 잡았다: 지네 격퇴, 단백질 보너스
- 테스트 실패 → 비

명령: `/ant` 창 열기 · `/ant stats` 활용 기록 · `/ant reset` 새 군락. 군락은 세션이 끝나도 저장됩니다.

## 설치

Claude Code 터미널 입력창에서:

```
/plugin install ant-nest --marketplace findot-ai/ant-nest
```

마켓플레이스 추가를 물으면 `y`, 범위는 사용자(user)를 고릅니다.

셸에서:

```
claude plugin install ant-nest --marketplace findot-ai/ant-nest
```

데스크톱 앱에서는 입력창 옆 + → Plugins → Add marketplace에 `findot-ai/ant-nest`를 넣고 Add plugin을 누릅니다.

데스크톱 앱에서는 옆 창에 도트 그림으로, 터미널에서는 반 블록 문자로 그립니다. 터미널에서는 폭이 좁으면 창이 자동으로 뜨지 않으니 `/ant`로 여세요.
